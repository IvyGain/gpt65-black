# GRT65 BLACK EDITION

Custom ultra-thin Bluetooth LE trackpad + 3-key macOS controller, based on the geek-rabb1t GRT65-EXP Kit.

**Status:** Phase 1 — source audit. No custom PCB or wireless firmware has been verified.

## Targets
- Touchpad above three horizontally aligned Kailh Choc V1 Sunset keys with MBK black 1U caps.
- Bluetooth LE keyboard + pointing HID, USB-C rechargeable battery, physical power switch.
- RGB underglow adjustable by a future macOS app.
- Matte black enclosure, target **12 mm maximum height including keycaps** (not yet proven).

## Ordered
Sunset switches x3; MBK black 1U keycaps x10; Seeed XIAO nRF52840 x1; key puller x1. Original GRT65-EXP Kit is unassembled.
